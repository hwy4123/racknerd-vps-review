1. **退款期只有72小时。** 行业常规是30天，它只给3天，而且这个政策在官网首页并不显眼。想清楚再买，买完立刻测。
2. **只有工单支持，没有在线客服。** 官方称7×24、平均10分钟内回复，Trustpilot上甚至有用户被官方主动通知服务器疑似被入侵；但那家做12个月监测的测评站实测工单平均4–8小时才回，质量评价是“够用但不惊艳”。半夜出问题，做好等几小时的准备。
3. **完全无管理。** 装环境、安全加固、故障排查全靠自己，官方不提供cPanel或代维服务。
4. **账单和服务器是两个面板。** 账单在WHMCS，服务器管理在NerdVM/SolusVM，重装系统、开控制台要去后者。第一次用容易找错地方。
5. **违规处理下手快。** Trustpilot有用户反馈，服务器在周末收到一封警告邮件后被直接删除，且没有备份可恢复。重要数据务必定期备份到机器之外，官方邮件尤其是滥用通知，收到就马上处理。
6. **闪购低配档流量偏少。** 往年10.18美元档的套餐月流量只有1TB，目前主流促销档从2TB起步。跑大流量业务前，先看清对应档位的额度。
